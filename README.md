# Land Search Tool 🌍

Профессиональный набор инструментов для автоматизированного поиска и анализа свободных земельных участков через Национальную Систему Пространственных Данных (НСПД) и Росреестра.

## 🚀 Описание проекта

Проект представляет собой конвейер (pipeline) из трех этапов, который позволяет автоматизировать процесс поиска участков без собственников и аренды, а затем визуализировать их на карте.

### Этапы работы:
1. **`1.py` (Поиск):** Автоматический перебор кадастровых номеров в заданных диапазонах. Скрипт оснащен адаптивным ограничителем скорости (Rate Limiter), который подстраивается под нагрузку сервера НСПД, чтобы избежать блокировки IP.
2. **`2.py` (Фильтрация):** Проверка найденных номеров на наличие владельцев или договоров аренды. На выходе формируется список только «свободных» участков.
3. **`3.py` (Визуализация):** Загрузка геометрии (координат границ) для отфильтрованных участков и создание файлов в формате GeoJSON.

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Библиотеки:** 
  - `asyncio` — для высокопроизводительных асинхронных запросов.
  - `pynspd` — для взаимодействия с API НСПД.
  - `dataclasses` и `typing` — для строгого структурирования данных.

## 📦 Установка и запуск

### 1. Регистрация в API-Cloud (Обязательно!)
Для работы скрипта `2.py` (фильтрация владельцев) требуется доступ к API. 
**Необходимо зарегистрироваться в системе API-Cloud**, получить API-ключи и добавить их в конфигурационный файл `.env`. Без этого этапа фильтрация по собственникам будет недоступна.

### 2. Клонирование репозитория
```bash
git clone https://github.com/ammosovmaxim/land-search.git
cd land-search
````

### 3\. Установка зависимостей

```
pip install pynspd
```

### 4\. Настройка окружения

Создайте файл `.env` в корневой папке проекта на основе примера `.env.example` и впишите ваш персональный ключ от API-Cloud.

### 5\. Порядок запуска

Запускайте скрипты строго по очереди:

**Шаг 1: Поиск номеров (`python 1.py`)**

- **Настройка квартала:** По умолчанию в скрипте установлен тестовый квартал. Чтобы указать свой, вы можете:
  - _Способ А (через терминал):_ Запустить скрипт с флагом `--quarter`, например:
    `python 1.py --quarter 77:01:000`
  - _Способ Б (в коде):_ Открыть `1.py`, найти строку 1241 `default="77:01:000"` и заменить значение на ваш кадастровый квартал.
- **Запуск:** После запуска скрипт начнет сканировать кадастровый квартал на наличние массивов (диапазон ввести в строках 1061, 1062, например: `array_start = 1`, `array_end = 100`) как все массивы будут найдены, попросит вас ввести **диапазоны номеров** в формате `НАЧАЛО-КОНЕЦ` можно ввести несколько (например, `1-1000`, `5000-20000`).
- Чтобы начать сканирование, нажмите **Enter** на пустой строке.

**Шаг 2: Фильтрация владельцев (`python 2.py`)**

- Скрипт берет результаты первого этапа и отсеивает участки, у которых есть собственник или аренда (требует API-Cloud).

**Шаг 3: Генерация карты (`python 3.py`)**

- Создает финальный GeoJSON файл с границами всех найденных свободных участков.

## 🗺 Визуализация результатов

После работы `3.py` в папке `geojson_results` появится файл `all_parcels.geojson`.

### Вариант 1: Быстрый просмотр (Браузер)

1. Перейдите на сайт [geojson.io (https://geojson.io)](<https://geojson.io>).
2. Перетащите файл `all_parcels.geojson` в окно браузера.

### Вариант 2: Профессиональный анализ (QGIS)

Для детального изучения участков рекомендуется использовать **QGIS**:

1. Откройте QGIS и создайте новый проект.
2. Добавьте слой `all_parcels.geojson` (перетаскиванием в программу).
3. Для наложения участков на реальную местность установите плагин **QuickMapServices**.
4. В меню `Web` → `QuickMapServices` → `Google` выберите **Google Satellite** или **Google Road**.
5. Теперь вы увидите границы участков прямо на спутниковых снимках Google.
